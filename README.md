# Hale & Rowan

Architecture studio and professional services landing. Limestone, copper, charcoal, and geometric display type. Light-custom: logo, colours, fonts, copy, and section on/off.

Live demo: https://hale.little.website/

## Features

- Architecture studio and professional services landing
- Light-custom: logo, colours, fonts, and copy
- Section on/off for hero, practice, projects, approach, studio, and contact
- Limestone, copper, and charcoal palette
- Geometric display type (Syne)
- Fully responsive Astro SSG

## Design

Typography:
- display: Syne
- ui: Manrope

Colors:
- Charcoal: #2c241b
- Copper: #8c4a2f
- Paper: #f7f3ec
- limestone: #c4b7a2

## Customization

Light-custom: logo, colours, fonts, copy, and section on/off.

Edit src/data/site.ts and CSS variables in src/styles.

Page sections:
- Hero
- Practice
- Projects
- Approach
- Studio
- Contact

Use cases:
- Architecture studios
- Professional services firms
- Design practices
- Studio portfolios

## Stack

Astro 5 SSG, CSS variables, TypeScript, Vite.
Fonts: Syne, Manrope
